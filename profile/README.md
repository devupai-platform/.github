## About DEVUP AI

**DEVUP AI** is an Algerian AI infrastructure platform combining a
multi-model inference gateway with on-demand Cloud GPU and CPU compute.

Developers, startups, research teams, and businesses can access leading AI
models, deploy high-performance compute instances, and manage their
infrastructure through one unified platform with native billing in
**Algerian Dinar (DZD)**.

DEVUP AI provides:

- OpenAI-compatible APIs
- DEVUP-native multimodal APIs
- More than 170 AI models
- On-demand Cloud GPU instances
- Scalable Cloud CPU infrastructure
- Official developer SDKs
- API key and usage management
- Real-time billing and request telemetry
- Local payment access
- Infrastructure status and operational monitoring

## Quick Start

### Official Node.js and TypeScript SDK

Install the official SDK:

```bash
npm install devupai
```

Create a client and send your first request:

```typescript
import DevupAI from "devupai";

const client = new DevupAI({
  apiKey: process.env.DEVUP_API_KEY!,
});

const response = await client.chat.completions.create({
  model: "deepseek-ai/DeepSeek-V4-Pro",
  messages: [
    {
      role: "system",
      content: "You are a concise technical assistant.",
    },
    {
      role: "user",
      content: "Explain artificial intelligence in one paragraph.",
    },
  ],
});

console.log(response.choices[0]?.message?.content);
console.log("Cost:", response._devup?.cost_dzd, "DZD");
```

### OpenAI-Compatible API

```bash
curl https://api.devupai.com/v1/chat/completions \
  -H "Authorization: Bearer $DEVUP_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "deepseek-ai/DeepSeek-V4-Pro",
    "messages": [
      {
        "role": "user",
        "content": "Hello from Algeria!"
      }
    ],
    "max_tokens": 256
  }'
```

Configure your API key securely:

```bash
DEVUP_API_KEY=sk-devup-your-api-key
```

> Never expose API keys in public repositories, screenshots, browser bundles,
> or client-side environment variables.

## Privacy and Data Handling

DEVUP AI is designed to process inference workloads without using customer
content for model training.

- Prompts and completions are not used to train or fine-tune models.
- Inference content is processed inside isolated compute environments.
- Usage metadata such as timestamps, model, token counts, latency, and cost may
  be recorded for billing and platform operations.
- Usage metadata does not include prompt or completion content.
- Temporary in-memory caching may be used to improve response latency.
- Customer inference content is not written to persistent storage by the
  managed inference pipeline.

Read the full legal and infrastructure documentation before processing
regulated or highly sensitive data.
